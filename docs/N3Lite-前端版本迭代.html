版本号规则

前端版本号采用 三段式：V{A}.{B}.{C}

段位 名称 递增条件 说明
A 主版本号 UI 大改版 / 框架升级 整体视觉重构、前端框架更换等重大变更。当 A 递增时，B / C 归零
B 功能版本号 新增页面或模块 新增独立功能页面（如 App 用户管理）。当 B 递增时，C 归零
C 修复优化号 Bug 修复 / UI 优化 样式调整、交互优化、性能优化、Bug 修复
